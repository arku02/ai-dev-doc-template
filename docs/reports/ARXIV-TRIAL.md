# Python 實際專案試用摘要

本頁整理 arxiv-digest 的兩輪歷史試用，用來說明模板在既有 Python 專案中的使用結果。一般使用者不需要安裝 arxiv-digest。

## 試用結果

| 日期 | 試用內容 | 當時的驗證結果 |
|---|---|---|
| 2026-09-18 | 修正論文抓取上限、失敗後的續抓起點與重試提示 | 14 項離線功能測試通過；完成兩次變更與封存，最終正式規格嚴格驗證通過 |
| 2026-09-26 | 在第二版隔離副本新增本機論文摘要預覽 | 30 項離線測試通過（原有 14 項、新增 16 項）；完成審查、實作、verify 與 archive，兩份正式規格嚴格驗證通過 |

第二輪功能讀取本機 JSON，顯示論文標題、原始摘要及連結，處理空資料與輸入錯誤。它不生成摘要，也不對外推送；本輪功能未套回原專案。

## 對模板的改善與觀察

- 第一輪促成 Python unittest 適配，以及封存後正式規格的檢查。
- 第二版讓工具依賴集中在 `.integration/`，並在副本中保留原有規格與歷史，完成一次新增功能的交付。
- 文件齊全不代表功能完成：測試必須真正執行，需求、任務與測試需要有明確對應，最後以驗證及封存回條核對結果。
- 第二輪是特定案例的配置與驗證，不代表已提供通用的舊版升級工具。

## 驗證限制

上述結果來自當時的 Windows、Node 與 Python 本機環境。Python 沿用既有套件，未驗證依 requirements.txt 從乾淨環境重建。

測試使用模擬回應及記憶體資料庫，沒有驗證真實 arXiv、MySQL 或 Telegram 服務；SQLite 測試不等同 MySQL 實機驗證。這些結果不代表已完成部署、排程或對外推送。
